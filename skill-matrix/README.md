# Skill Matrix — ក្រុមការងារប្លង់ផលិត (Furniture Shop Drawing)

| Sheet | ខ្លឹមសារ |
|---|---|
| 1_Levels | និយមន័យកម្រិតជំនាញ 0–4 និងរបៀបប្រើ |
| 2_SkillMatrix | ជំនាញ 34 ក្នុង 6 ក្រុម × បុគ្គលិក 6 នាក់ (វាយលេខ 0–4, ពណ៌ស្វ័យប្រវត្តិ, មធ្យមក្រុម, ⚠ ខ្វះអ្នកបម្រុង) |
| 3_RoleTarget | កម្រិតតម្រូវតាមតួនាទី: Junior Drafter, Drafter, Senior Drafter, CNC / Cut-list Programmer, Team Lead / Checker |
| 4_Gap | គម្លាត = បច្ចុប្បន្ន − តម្រូវ (គណនាស្វ័យប្រវត្តិ) |
| 5_TrainingPlan | ផែនការបណ្តុះបណ្តាល (បញ្ជីជ្រើស: វិធីសាស្ត្រ, ស្ថានភាព) |

ក្រុមជំនាញ: A. ការអាន និងស្តង់ដារប្លង់ · B. កម្មវិធីកុំព្យូទ័រ · C. សម្ភារៈ និងគ្រឿងបន្លាស់ · D. រចនាសម្ព័ន្ធ និងការតភ្ជាប់ · E. ឯកសារផលិតកម្ម · F. គុណភាព និងការសម្របសម្រួល

លេខវាយតម្លៃក្នុងឯកសារជាឧទាហរណ៍ — សូមជំនួសដោយការវាយតម្លៃពិត។ ពុម្ពអក្សរ: Khmer OS Battambang។
